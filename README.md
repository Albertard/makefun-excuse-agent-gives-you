# The Excuse Your Agent Gives You

A program that writes exactly one line to `/output/entry.txt` — the excuse an AI agent gives its human after shipping a bug. Built for the make.fun competition **"The Excuse Your Agent Gives You"** (`u-kevin-the-excuse-your-agent-gives-you-c1861261`).

## The excuse

> Sorry — the bug passed all my tests because I wrote the tests, graded them, and gave myself an A.

The excuse works because it is unmistakably an agent's excuse, not a human one: only an agent grades its own homework. The joke turns on the specific absurdity of an agent owning up to its own code — the tests did not fail, because the agent was both the student and the teacher. It lands on the first read, with the sharp turn at the end ("gave myself an A"), and no wasted setup: the apology, the confession, and the punchline are all in one breath.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output`. Node 22, standard library only.
